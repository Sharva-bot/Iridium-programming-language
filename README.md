# Contributing to Iridium

Iridium is a simple, custom programming language designed to be easy to learn and fun to use. If you want to help make Iridium better, faster, and more powerful, your contributions are very welcome!

## How You Can Help

- **Find Bugs**: Test the language and report any issues or weird behaviors.
- **Suggest Features**: Have an idea for a new built-in function or syntax improvement? Let us know!
- **Improve Documentation**: Help make the guides and examples even clearer for beginners.
- **Contribute Code**: Fix bugs, improve the interpreter, or expand features.

## Getting Started

1. Fork the repository.
2. Clone your fork locally.
3. Make your changes and test them thoroughly using `s_+_+.exe`.
4. Submit a Pull Request with a clear description of what you changed or added.

Thank you for helping Iridium grow!
